# VSCodium AppImage Builder

GitHub Actions workflow that builds a launch-profiled, DWARFS-compressed **VSCodium AppImage** for x86_64 and publishes it as a GitHub Release.

[![Build VSCodium AppImage](https://github.com/FadlyAndryanto/VSCodium-AppImage/actions/workflows/build-appimage.yml/badge.svg)](https://github.com/FadlyAndryanto/VSCodium-AppImage/actions/workflows/build-appimage.yml)

## Releases

Each built release uses the bare upstream VSCodium version as its tag, such as `1.143.17232`, and contains:

| Asset | Description |
| --- | --- |
| `*.AppImage` | The final x86_64 AppImage |
| `*.AppImage.zsync` | zsync metadata for delta updates |
| `appinfo` | AppImage metadata generated by `appimagetool` |
| `SHA256SUMS` | SHA-256 checksums for the AppImage, zsync file, and `appinfo` |

The release title is:

```text
VSCodium <version> — DWARFS AppImage
```

## How It Works

The workflow:

1. Resolves the requested VSCodium version or retrieves the latest upstream release.
2. Validates that the version has the format `X.Y.Z`.
3. Checks whether a matching release already exists.
4. Skips building unless rebuilding was explicitly requested or no matching release exists.
5. Installs FUSE dependencies.
6. Downloads the latest `pkgforge-dev/appimagetool`.
7. Downloads the upstream `codium_<version>_amd64.deb` package.
8. Extracts the package into `AppDir`.
9. Creates the desktop entry, icon, and `AppRun` launcher.
10. Builds and validates the AppImage and zsync metadata.
11. Generates SHA-256 checksums.
12. Creates or updates the GitHub Release.

The build uses DWARFS compression, launch-profile optimization, and embedded zsync update metadata.

## Workflow Triggers

### Scheduled build

The workflow runs every three hours:

```text
23 */3 * * *
```

Scheduled runs check the latest upstream VSCodium release and only build when a matching release does not already exist.

### Manual build

Run the workflow from **Actions → Build VSCodium AppImage → Run workflow**.

| Input | Type | Default | Description |
| --- | --- | --- | --- |
| `version` | string | Latest upstream release | Optional VSCodium version, such as `1.143.17232`. A leading `v` is removed. |
| `rebuild` | boolean | `false` | Rebuild and replace release assets even if the version has already been released. |

## Build Environment

- Runner: `ubuntu-24.04`
- Architecture: x86_64
- Timeout: 30 minutes
- Concurrency: one release build at a time
- Queued builds do not cancel existing builds
- FUSE: `/dev/fuse` must be available
- `appimagetool`: latest release from `pkgforge-dev/appimagetool`

The workflow installs `fuse3`, `libfuse2`, and supporting FUSE tools. It aborts if `/dev/fuse` is unavailable.

## AppImage Update Information

The generated AppImage contains:

```text
gh-releases-zsync|FadlyAndryanto|VSCodium-AppImage|latest|*-x86_64.AppImage.zsync
```

This allows AppImageUpdate-compatible clients to discover updates using the repository’s latest GitHub Release.

## Validation

Before publishing, the workflow verifies that:

- `/dev/fuse` exists.
- The upstream `.deb` package contains the required desktop file, icon, and VSCodium executable.
- Exactly one non-empty `.AppImage` is generated.
- Exactly one non-empty `.AppImage.zsync` file is generated.
- The DWARFS profile was generated.
- The `appinfo` file exists.

The workflow does not build an AppImage if a matching GitHub Release already exists unless `rebuild` is enabled.

## Permissions

The workflow requires write access to repository contents to create and update releases:

```yaml
permissions:
  contents: write
```

It uses the automatically generated `GITHUB_TOKEN`; no additional secret is required.

## Local Reproduction

A local build requires an amd64 Linux system, FUSE, and `appimagetool`.

```bash
# Download and extract VSCodium
curl -fL \
  "https://github.com/VSCodium/vscodium/releases/download/<version>/codium_<version>_amd64.deb" \
  -o codium_<version>_amd64.deb

mkdir -p AppDir
dpkg-deb -x codium_<version>_amd64.deb AppDir
```

Then generate `AppDir/codium.desktop`, `AppDir/codium.png`, `.DirIcon`, and `AppDir/AppRun` similarly to the workflow, and build:

```bash
APPIMAGE_ARCH=x86_64 ARCH=x86_64 VERSION=<version> \
  appimagetool \
    --verbose \
    --optimize-launch \
    --profile-timeout 45 \
    --dwarfs-profile codium.dwarfsprofile \
    --update-info \
      'gh-releases-zsync|FadlyAndryanto|VSCodium-AppImage|latest|*-x86_64.AppImage.zsync' \
    AppDir \
    --output dist
```

Finally, generate checksums:

```bash
cd dist
sha256sum *.AppImage *.AppImage.zsync appinfo > SHA256SUMS
```
